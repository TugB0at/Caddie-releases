# Caddie

A second-monitor companion for [GSPro](https://gsprogolf.com/). It reads the
player cards on screen and shows what each shot **plays like** once lie,
elevation and altitude are counted. In a scramble it tracks whose shots the
team used, and when the round ends it shows the totals: shots used, longest
tee shot, closest to the pin, and a shot clock per player.

Caddie never connects to GSPro. It only looks at the screen and the files
GSPro writes to disk.

## Download

**[Download the latest Caddie.exe](https://github.com/TugB0at/Caddie-releases/releases/latest/download/Caddie.exe)**

No GitHub account needed. Older versions and what changed in each are on the
[Releases](https://github.com/TugB0at/Caddie-releases/releases) page.

## Install

1. Double-click `Caddie.exe`.
2. Windows may say **"Windows protected your PC"**, because the app isn't
   signed. Click **More info → Run anyway**. It only asks once.
3. Caddie asks **Install Caddie?** Click **Yes**. It adds a Start menu and a
   Desktop shortcut and starts. No admin rights needed.

Windows 10 or 11. Nothing else to install.

## Use

1. Start GSPro, then Caddie.
2. Drag the Caddie window to your second monitor (or right-click → **Move to
   monitor**). It remembers where it goes.
3. Play. The first time on a course, click the gold **Set altitude** pill and
   enter the course's height in feet.

Right-click the window or click the gear for settings: lie penalties, slope,
altitude, and the shot clock sound. Press `T` to show the totals at any time.

## Update

Download the new `Caddie.exe` and double-click it. It offers to update your
installed copy and keeps your settings.

## Uninstall

Windows Settings → Apps → Caddie → Uninstall.

## Something wrong?

If Caddie shows nothing while a player card is on screen:

1. Right-click → **Clear saved card region**, and give it a few seconds.
2. Still nothing, or anything else wrong? With the card on screen, right-click
   → **Problem report...** (also in Settings). It saves one file to your
   Desktop, "Caddie problem report ….zip", and opens the folder with it
   selected. Send that file over, with a line about what you expected to see.
